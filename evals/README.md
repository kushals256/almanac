# evals: separate test harness (Promptfoo)

The test harness is deliberately separate from the app: its own `package.json`, its own database (`data/eval.db`), its own port (3100). The only hook in the app is `POST /api/chat?mode=json`, which runs the same pipeline and returns one JSON response.

```bash
cd evals
npm install
npm run seed        # build real history on simulated past days (3, 9, 10, 11 Nov) into data/eval.db
npm run serve       # eval server on :3100 with the clock at Thu 12 Nov 2026 (leave running)

# in a second terminal
npm run eval        # regression suite: brief queries + every past bug
npm run eval:sim    # simulated users: multi-turn personas
npm run redteam     # adversarial probes (prompt extraction, false premises, hijacking, …)
npm run view        # browse results
```

Grading uses Groq `openai/gpt-oss-20b` (the app only uses it as a fallback), via the keys in `../.env`. Simulated users and red-team probes are generated by Promptfoo's hosted models.

Every failure goes into [FINDINGS.md](FINDINGS.md) before anything is fixed.
