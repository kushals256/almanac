# Eval findings log

Testing is kept separate from building. Every failure from any suite is logged here first; fixes happen in batches after triage, and each fixed finding becomes a permanent regression test.

**Process:** test → log → triage → fix (batch) → retest → add regression test.

| Field | Meaning |
|---|---|
| ID | `F-<n>` |
| Suite | trials · regression · simulated · redteam |
| Severity | **S1** wrong/unsafe answer, fabricated fact or history · **S2** wrong route, missing part, bad format · **S3** latency, cost, polish |
| Decision | fix now · fix later · won't fix (with reason) |
| Status | open · fixed (commit/date) · verified (retest passed) |
