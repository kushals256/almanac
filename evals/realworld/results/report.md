## ✅ breadth · chat · ttft 1093 ms · 0 searches · verify - · judge 5
> (2026-11-12T08:14 Asia/Kolkata) How do I reverse a linked list in Python?

Sources: none

You can do it iteratively or recursively. Here's the clean iterative version:

```python
def reverse(head):
    prev = None
    curr = head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev
```

It walks the list once, flipping each node's `next` pointer to point backward, and returns the new head (`prev`). Time: O(n), space: O(1).

If you prefer recursion:

```python
def reverse(head):
    if not head or not head.next:
        return head
    new_head = reverse(head.next)
    head.next.next = head
    head.next = None
    return new_head
```

Same complexity, though recursion adds O(n) stack space. The iterative one is usually the safer bet for long lists.
