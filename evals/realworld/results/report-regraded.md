## ✅ breadth · chat · ttft 712 ms · 0 searches · verify -
> How do I reverse a linked list in Python?

Sources: none

Here's a simple iterative approach in Python:

```python
def reverse_linked_list(head):
    prev = None
    curr = head
    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node
    return prev
```

This works by maintaining three pointers: `prev`, `curr`, and `next_node`. As you iterate through the list, you reverse the direction of each node's `next` pointer. The time complexity is O(n) and space complexity is O(1).

If you also want a recursive alternative:

```python
def reverse_linked_list_recursive(head):
    if not head or not head.next:
        return head
    new_head = reverse_linked_list_recursive(head.next)
    head.next.next = head
    head.next = None
    return new_head
```

The key difference: the iterative version is generally preferred in practice because it uses constant space, while the recursive version is sometimes considered more elegant but uses O(n) stack space for the call stack.
