## k1 · stable · route=chat · ttft 511ms · 0 searches · verify -
> What's the difference between TCP and UDP?

Sources: none

TCP and UDP are both core protocols in the internet's transport layer, but they handle data delivery differently:

*   **TCP (Transmission Control Protocol):** Connection-oriented. It establishes a handshake before sending data and guarantees delivery, maintaining the exact order of data packets. If a packet is lost, TCP requests a retransmission. This makes it reliable and ideal for web browsing, email, and file transfers, but slightly slower.
*   **UDP (User Datagram Protocol):** Connectionless. It sends data packets over the network without establishing a connection or guaranteeing that each packet arrives in order or even at all. It is much faster and uses less overhead, making it perfect for real-time applications like live video streaming, online gaming, and voice calls, where minor data loss is acceptable.
